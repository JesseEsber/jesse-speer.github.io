How the work gets built

01 — APPROACH

Regulatory training has a trap: teach to the audit and the caregiver forgets it by the next shift. Every module runs through the same five gates to avoid that.

01 / ANALYZE

Read the regulation

Start from the actual standard — CHAP, CLASS, state EVV mandate — and find where real practice drifts from it.

02 / DESIGN

Pick the format on purpose

A password policy doesn't need the same treatment as an abuse-reporting scenario. Format follows the stakes.

03 / DEVELOP

Build for the caregiver's day

Short video, a game, or a scenario — built for someone learning between visits, not sitting in a classroom.

04 / IMPLEMENT

Ship it audit-ready

Documented, trackable, and mapped to the exact requirement it satisfies — so it holds up when CHAP asks.

05 / EVALUATE

Check it stuck

Not just completion rates — whether the behavior shows up on the next home visit.

About

04 — PROFILE

I didn't start in instructional design — I started in HR and internal audit, preparing home health agencies for CHAP, DBMD, and CLASS surveys. That's the part of my background most instructional designers don't have: I've sat across from the surveyor, not just built the training meant to satisfy them.

That shows up in how I build now. As Sr. Instructional Designer at WellMed Medical Management, I run the full production pipeline myself — storyboard, script, voiceover, videography, edit — using ADDIE, the enAble methodology, Lean Six Sigma, and Kirkpatrick evaluation on every deliverable, not as separate initiatives but as one discipline.

I'm working toward performance consulting next: using that audit background to ask whether a gap is actually a training problem before defaulting to building a course.
